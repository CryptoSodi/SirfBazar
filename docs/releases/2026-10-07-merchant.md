# Merchant frontend release - 2026-10-07

Publishes the current merchant workspace to shop.sirfbazar.com from apps/shop. Source: Gorcery New Structure/sirfbazar-shop. Customer and admin application sources are unchanged.

## Changes
- Updated merchant workspace, branding, sign-in, onboarding and recovery pages.
- Removed direct Windows-only Tailwind native dependency for Linux deployment compatibility.
- Selected Node.js 22 and applied compatible dependency security fixes.
- Production API remains https://api.sirfbazar.com/api.

## Verification
- npm run build: TypeScript and Vite production build passed.
- npm audit fix: zero remaining vulnerabilities.
- Browser: sign-in required-field validation and focus; desktop signup link; keyboard navigation between public auth routes; signup and recovery layout at 320px without horizontal overflow; sign-in images loaded; no browser console errors observed during public-route checks.
