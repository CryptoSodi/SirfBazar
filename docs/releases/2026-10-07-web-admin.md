# Customer and admin frontend release

Scope: publish the current customer website to sirfbazar.com and admin dashboard to admin.sirfbazar.com. Backend, merchant, POS, and mobile sources are unchanged.

Customer runtime upgraded to Next.js 16.4.0 because the old version has unresolved critical advisories. React 18 remains supported by this release (deprecated for the next major). Production dependency audit: zero findings. Admin compatible dependency updates: zero audit findings. Customer build-only Tailwind 3 dependencies retain seven audit findings; no forced Tailwind major upgrade was included.

## Entry-screen interface review

Scope: customer homepage and admin sign-in, including the existing API-unavailable state. Stacks: Next.js/Tailwind 3 and React/Vite/Tailwind 4. Project AGENTS.md and existing customer implementation/visual-parity records were inspected.

| Domain | Evidence inspected | Result |
| --- | --- | --- |
| Accessibility | Rendered input labels, admin keyboard focus, source landmarks and alert | Demo sign-in text removed; native required/email validation and error alert added. Screen-reader testing not verified. |
| Layout | Customer and admin entry pages at narrow width and desktop | No document overflow at 320px; no broken homepage images. Exact 200% zoom and RTL not verified. |
| Writing | Entry labels and error recovery | Admin demo credentials removed; customer unavailable state offers retry. |
| Typography | Admin mobile inputs, homepage hierarchy | Admin mobile inputs raised to 16px; no clipped entry controls observed. |
| Color | Admin sign-in source and rendered colors | Footer/secondary caption moved from slate-400 to slate-500 for readable contrast on white. Full theme contrast audit not verified. |
| UI | Entry-page screenshots and form structure | No additional release-blocking issue observed within this scope. |

## Verification

- Customer production build: passed; all routes compiled and typechecked.
- Admin production build: passed.
- Customer production dependency audit: zero findings.
- Admin dependency audit: zero findings.
- Previewed customer homepage and admin sign-in with production API configuration.
- Production API remains HTTP 502. Login, catalog retrieval, checkout, authenticated dashboard, and other backend-dependent workflows are not verified by this frontend release.

Verdict: Approve for the inspected frontend entry-screen scope only. This is not approval of end-to-end commerce functionality.
