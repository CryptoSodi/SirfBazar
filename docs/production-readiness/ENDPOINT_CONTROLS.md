## How To Read The Matrix

B = brief baseline; A = added since brief; R-only noted above. Actor role sets are exact source decorators; SUPER_ADMIN inherits ADMIN through RolesGuard. AUTH = valid global JWT, not automatically CUSTOMER/merchant. Public guest operations still require the bearer-like guest token except creation. Public discovery remains anonymous.

Boundary codes below contain the input/projection and sensitive-data scope; **global whitelist only applies to concrete runtime DTO classes**. Inline interfaces/any bodies/queries are not validated merely because ValidationPipe is installed. Ordinary JSON/urlencoded limit is 100 KiB; bulk preview/upload scoped 6 MiB; multipart image 6 MiB and private document 10 MiB. These are byte limits, not content safety or request quotas.

Every matrix row is overall PARTIAL because required policy/test coverage is incomplete, or UNVERIFIED for an untested boundary. It does not mean its primary authorization logic is missing. Tests listed are candidate/scenario mappings with a historical subset where stated, not proof that the actual endpoint or every actor was tested. No route gets a full production VERIFIED label.

### Cache And Mutation Codes

No backend response or negative cache was traced in service/bootstrap. PUBLIC source-read means eligible for a future explicitly keyed representation cache, not currently cached. ACTOR-SENSITIVE is never safe for an undimensioned public cache. PRIVATE intended is not evidence that proxy/browser Cache-Control is enforced. Static files are separate below. Negative cache/Bloom are NOT_NEEDED_YET.

READ is not universally non-mutating: active-cart GET can allocate carts. ID-CHECKOUT uses order primary key + actor/intent audit fingerprint and same transaction cart/stock/order/payment/audit. ID-POS does analogous cashier/merchant/fingerprint stock/receipt audit with optional legacy ID. ID-BULK commits per-row saved audit outcomes. STATE/TX conditional claims prevent repeat money/stock effects, but may return a state error rather than same-result replay. Provider notifications are post-commit without a durable outbox across all these codes.
