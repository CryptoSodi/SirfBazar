# SirfBazar customer mobile: exact design pack

Start with [START_HERE.md](START_HERE.md). Open the [interactive reference](reference/SirfBazar_Customer_Mobile.html), then give Codex the [full implementation prompt](CODEX_CUSTOMER_EXACT_PROMPT.md) inside your existing project.

This pack targets the existing native apps/customer-app and existing apps/api, not a new website or a replacement backend. Read [COMMANDS.md](COMMANDS.md) for extraction and launch instructions, [API_CONTRACT_MAP.md](API_CONTRACT_MAP.md) for integration, and [QA_REPORT.md](QA_REPORT.md) for the limits of the completed local checks.

All 84 reference screen images use fictional data. Their identity, quote, ordering and tracking states are visual demonstrations only. Normal app screens must use the real API and native OS behavior.
