# SirfBazar brand assets

These are the supplied, approved vector marks. The usage rules and color values are in [`BRANDING.md`](../../BRANDING.md). Do not typeset the wordmark or Urdu slogan as a substitute for these artworks.

The same SVGs are copied to each web app's `public/brand/` directory. Expo apps use PNG renditions in their own `assets/brand/` directories because their app icons, splash screens, and React Native `Image` components require raster files. Regenerate those PNGs from the SVG masters if the approved artwork changes.

Use `sirfbazar-primary.svg` on light backgrounds, `sirfbazar-reverse.svg` on dark backgrounds, `sirfbazar-horizontal-no-slogan.svg` in compact headers, and the basket-only variants where a full wordmark would not be legible.
